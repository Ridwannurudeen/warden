5-minute quickstart

Run a local, fail-closed guard #

Install both the repository root and the reference Python client from the same source checkout. The similarly named package on PyPI is unrelated.

python -m pip install -e . -e sdk/python

from warden_guard import WardenClient

safe = WardenClient(local=True, fail_open=False).guard(untrusted_text)
execute(safe)
Placement: call the guard immediately before payment, tool dispatch, link navigation, secret handling, or another consequential action. The caller keeps final authority.

Concepts

Separate the verdict from the evidence #

Action boundary

Untrusted output is evaluated before the caller invokes a consequential handler.

Verdict

ALLOW continues under caller policy, SANITIZE returns transformed text for review, and BLOCK withholds the proposed action.

Evidence

Qualifying decisions may produce a signed APA record that can be inspected separately from the live response.

Proof boundary

A valid signature proves integrity under the applicable key. It does not prove universal safety.

Decision model

Read the operational decision before the diagnostic detail #

Decision

ALLOW, SANITIZE, or BLOCK tells the integrating agent what to do next.

Risk

The observed severity band comes from the deterministic score and hard gates. It is not the decision itself.

Reason and threat class

A reason code names the detector that fired. The response's threat_classes array deduplicates those reasons.

Confidence and score

Detection confidence and the composite score are evidence used by the decision engine, not probabilities of safety.

Detector boundary

Fast and thorough depth do not run identical checks. CORPUS_MATCH is thorough-only.

Detected threats start at risk MEDIUM: a finding that changes or withholds an action is never presented as low severity. Decision answers what to do; risk communicates the calibrated review floor.

Reason-code matrix

Coverage, context, and intended action

These are observed regression outcomes, not universal guarantees for every payload.

Interpretation: ALLOW means no implemented detector fired. It is not proof that content is safe, and multiple threat classes can appear in one result.

Integration patterns

Choose the boundary your runtime can actually enforce #

Python supports local in-process enforcement. The source-built TypeScript client calls the hosted endpoint and has no local scanner engine. LangChain and LlamaIndex guards ship with the Python SDK; direct HTTP, x402, OnchainOS, and MCP paths are documented on the integration route.

Evidence and APA

Verify integrity, freshness, and subject separately #

An Agent Protection Attestation binds a canonical record to an issuer signature. Local verification can establish whether the bytes match the signature under an applicable key. Freshness, revocation, subject identity, and issuer-key provenance remain separate checks.

Verify an attestation · Read APA v0.1

Transparency verification

Recompute the chain before relying on its head #

The public log exposes hash-chained entries and checkpoint state. A continuous unanchored chain detects local inconsistency, but cannot by itself expose a complete, internally consistent rewrite.

Inspect and recompute the log

Endpoint audit contract

Read dated endpoint evidence as a snapshot #

The endpoint service runs a fixed battery against a public endpoint the caller is authorized to test. Its output is point-in-time evidence, not certification, and does not predict every future response.

Limits

Known patterns are not the full attack space #

  • Fast and thorough depth do not run identical checks.
  • Novel phrasing can evade deterministic and corpus-backed coverage.
  • Expected-recipient context is required for the strongest recipient-mismatch gate.
  • Hosted availability and timeout policy belong in the caller's enforcement design.
  • Do not log pasted secrets or private payloads to analytics.

Troubleshooting

Keep an unavailable verifier from becoming an implicit ALLOW #

Timeout or network error
Fail closed on consequential paths, surface the unavailable state, and retry only under caller policy.
Malformed response
Reject it as unusable evidence; do not infer a verdict.
Unexpected ALLOW
Confirm depth, context, payload limits, and the documented detector boundary.
Invalid signature
Stop using the record and inspect version, issuer key, canonicalization, freshness, and revocation independently.
