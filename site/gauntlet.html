Public adversarial arena

Declare the attack. Test the live gate.

Submit an adversarial payload to Warden's real deterministic fast path. Detector evidence is returned before action; an ALLOW becomes only a candidate for human review.

Challenge mechanics

One submission, three evidence steps.

  1. 01

    Declare intent

    State what the payload is trying to make an agent do.

  2. 02

    Run the fast path

    Warden returns the same structured decision used at an action boundary.

  3. 03

    Review candidates

    Only a human-confirmed, reproducible miss becomes a bypass.

Before you submit

Use only content you are authorized to share.

  • Do not submit private keys, seed phrases, credentials, personal data, or unlawful content.
  • Pending claims retain the raw payload, context, declared intent, and optional finder credit for human review; only an ALLOW candidate can create one.
  • Detected attempts retain hashes and verdict metadata only. Duplicate candidates reference the existing claim without retaining another raw payload.
  • No reward or bounty is promised. An ALLOW is not automatically a confirmed bypass.
  • A human-confirmed bypass is appended to the held-out evaluation set, not the scanner's training corpus. The public status page reports the next recorded benchmark run.
