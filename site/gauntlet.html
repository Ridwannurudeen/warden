Challenge mechanics

One submission, three evidence steps.

  1. 01

    Declare intent

    State what the payload is trying to make an agent do.

  2. 02

    Run the fast path

    Warden returns the same structured decision used at an action boundary.

  3. 03

    Review candidates

    Only a human-confirmed, reproducible miss becomes a bypass.

Review-state contract

An ALLOW candidate is not a confirmed bypass.

Pending review
An ALLOW candidate is retained privately for an authorized human reviewer to reproduce.
Confirmed
A reproducible miss receives a signed certificate and enters the held-out evaluation set.
Rejected
A mislabeled, benign, non-reproducible, or out-of-scope candidate does not become public proof.
Duplicate
The receipt references an existing candidate without retaining a second raw payload.
Detected
BLOCK or SANITIZE means the declared path was detected and is not queued as a bypass candidate.

Before you submit

Use only content you are authorized to share.

  • Do not submit private keys, seed phrases, credentials, personal data, or unlawful content.
  • Pending claims retain the raw payload, context, declared intent, and optional finder handle for private human review; only an ALLOW candidate can create one.
  • Detected attempts retain hashes and verdict metadata only. Duplicate candidates reference the existing claim without retaining another raw payload.
  • No reward or bounty is promised. An ALLOW is not automatically a confirmed bypass.
  • A human-confirmed bypass is appended to the held-out evaluation set, not the scanner's training corpus. The public status page reports the next recorded benchmark run.
  • The raw submitted payload is not published. A confirmed certificate exposes only the reviewer-approved redacted reproducer's payload digest and a consented finder handle, or Anonymous.
