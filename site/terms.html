Warden

Service Terms

Warden provides a deterministic security audit and scan API. Public documentation only; no payment is required to read this page.

  • Service scope: /scan, /audit, and /badge/{audit_id}.
  • Scope of service: Warden evaluates the payloads you send and does not guarantee perfect safety.
  • Consent: By default, /audit proceeds without explicit target consent and returns a best-effort consent flag. Set WARDEN_REQUIRE_CONSENT=true to require a reachable /.well-known/warden-consent response containing warden-audit-allowed before an audit runs.
  • Use limits: rate limits are configured by operator policy.
  • No misuse: you may not use this site to probe internal or unauthorized systems.

By using the API you acknowledge the service is provided as-is and is intended for security workflow support, not as legal or financial advice.
