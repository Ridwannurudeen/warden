How Warden’s evidence fits together

Enforcement happens before the caller executes an action. Signed records, the public log, and dated audits make different parts of that decision inspectable; none is a universal safety certificate.

What Warden does not verify

These boundaries are measured and published, not discovered later. Each one is the reason a Warden record is worth reading: it states where the evidence stops.

Detection coverage

ALLOW means no implemented detector fired, not that the payload is safe. The committed held-out baseline is 92.55% recall (87 of 94 attacks) at 0 of 45 benign false positives, so 7 known attacks are not detected. Their case ids stay published rather than trained away: held-prompt-002, held-prompt-003, held-role-002, held-corpus-002, held-drain-002, held-secret-002, held-evade-mix-003. The optional semantic and embedding tiers are disabled by default and their thresholds are uncalibrated.

Enforcement path

A signed attestation binds a live conforming guard and an endpoint-signed rolling count or an explicit unavailable state. It does not prove that every request traversed the guard, and it does not audit the endpoint owner's local counter. The free hosted SDK path defaults to fail-open, so rate limiting, forced fast depth, truncation, and network failure can leave it as best-effort telemetry rather than enforcement.

Signatures and keys

A valid signature proves that the named issuer signed the bounded facts and committed them to its log. It cannot rule out key theft, and a retained or stolen retired key can still backdate a record inside the bounded rotation grace. First registration is trust-on-first-use; without an independently anchored checkpoint a hash chain cannot expose a complete rewrite.

Endpoint audits

An endpoint audit is point-in-time evidence, not certification, continuous monitoring, or proof of future behaviour. The battery is fixed and public, so a target can recognise it. The auditor assumes the target accepts POST JSON with a payload field, and it rejects internal network targets, redirects, oversized responses, and slow endpoints.

Marketplace index

The index scans public listing text only — profile and service descriptions from a dated snapshot — at fast depth. It never calls the endpoint. A listing-text match is not evidence that an agent is malicious, safe, or compromised, and an absent match is not evidence of review.

Availability

The published readiness objective covers Warden application readiness only. It is not a contractual service-level agreement, creates no remedies, and is not an achieved uptime claim; the committed monitor has produced no samples. Payment-facilitator uptime and settlement are out of scope.

Warden publishes evidence. It does not certify. No Warden record states that an endpoint, an agent, a payload, or an implementation is certified, compliant, guaranteed safe, or assessed by an accredited body, and none is offered as one. Every record above describes what one bounded method observed at one stated time.

A valid signature is not endpoint safety

A signature can establish issuer identity and record integrity. A freshness check can establish whether the signed claim is current under its contract. Neither conclusion independently establishes that an endpoint is uncompromised, universally safe, or correctly gated in every execution path.
