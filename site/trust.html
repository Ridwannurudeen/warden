Warden Trust Layer · APA v0.1

The immune system of the agent economy.

Warden places deterministic enforcement before autonomous action, publishes an open proof of guard state, and makes ecosystem evidence visible without turning it into a trust seal.

Watch Attack Theater Read the open spec

Three interoperable pillars

Enforce locally. Attest openly. Inspect publicly.

Each pillar has a separate job and a visible boundary. None is presented as proof that an endpoint is permanently safe.

01 · Local enforcement

Run the deterministic engine in the agent process, without a network dependency or hosted rate limit. 

safe = WardenClient(local=True, fail_open=False).guard(untrusted_text)
02 · Agent Protection Attestation

APA binds an endpoint host to an Ed25519 key, live guard state, and a signed rolling 24-hour count or an explicit unavailable state that anyone can verify offline.

An honest proof boundary

Guard-live means exactly what the signature proves.

A valid, fresh APA attestation proves that the endpoint host controls its key and signed the stated rolling 24-hour count or an explicit unavailable state in its live guard proof. The issuer verifies that proof and separately signs the attestation record. It does not prove that every request traversed the guard or independently audit local counter state.
