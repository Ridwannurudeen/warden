How an audit becomes a badge

A badge is a signed record of one completed endpoint-audit result. It is not a live monitor or a security certification.

  1. 01Attest authorization and run

    The caller must own or be authorized to test the public target; the returned audit is not independent proof of permission.

  2. 02Record the result

    An eligible completed audit stores its target, result, issue time, and signature.

  3. 03Verify integrity

    The API recomputes the server-side signature for each registry request.

  4. 04Read the boundaries

    Target, result, time, and integrity remain separate facts on the detail page.
