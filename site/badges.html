Evidence contract

Four facts stay separate.

The interface does not collapse authorization, audit outcome, integrity, and time into a single trust seal.

  1. 01Scope

    The target host and fixed audit battery define what was checked.

  2. 02Outcome

    Grade, score, and cases blocked or flagged describe that one run.

  3. 03Integrity

    The API recomputes the stored record's signature for this request.

  4. 04Time

    The issue time bounds the evidence; no expiry or revocation model is claimed for these legacy records.
